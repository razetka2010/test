## 📖 Описание

**Знание Севера** — это современный веб-сайт корпорации, специализирующейся на разработке цифровых решений. Компания предоставляет полный спектр IT-услуг, включая разработку Telegram-ботов, создание образовательных платформ, обеспечение кибербезопасности и комплексные программные решения любого масштаба.

Сайт рассказывает историю создания компании — от первого неудачного проекта на курсе веб-программирования до победы в конкурсе технологий и создания полноценной корпорации.

## � Система управления документами

### Как это работает?

1. **Хранилище** — все документы хранятся в папке `/docs` на GitHub
2. **Конфигурация** — файл `public/documents.json` содержит метаданные
3. **Интерфейс** — страница `public/documents.html` отображает документы
4. **Функционал** — JavaScript автоматически загружает и фильтрует документы

### Быстрый старт с документами

#### 1. Создайте папку для документов
```bash
mkdir docs
```

#### 2. Добавьте документы в папку
```bash
# Скопируйте ваши PDF, DOCX и другие файлы в папку docs/
cp /path/to/your/document.pdf docs/
```

#### 3. Обновите documents.json
Откройте `public/documents.json` и добавьте описание документа:

```json
{
  "id": 7,
  "title": "Название документа",
  "category": "tech-spec",
  "description": "Описание документа",
  "fileName": "Document-Name.pdf",
  "icon": "fas fa-file-pdf",
  "date": "2024-02-15",
  "downloadUrl": "https://raw.githubusercontent.com/yourusername/yourrepo/main/docs/Document-Name.pdf"
}
```

#### 4. Загрузите файлы на GitHub
```bash
git add docs/
git add public/documents.json
git commit -m "Add: New documents"
git push origin main
```

#### 5. Проверьте результат
Откройте `https://ваш-сайт.com/documents.html`

### Категории документов
- `tech-spec` — Технические задания
- `methodology` — Методические материалы
- `guides` — Инструкции и руководства

## 🚀 Установка и запуск

### Переменные окружения

Для production задайте `DATABASE_URL`, `SESSION_SECRET` (длинная случайная строка)
и при необходимости `FRONTEND_ORIGIN`. Без `SESSION_SECRET` вход в админ-панель отключён.

### Вариант 1: Локальный запуск через веб-сервер

```bash
# Клонируйте репозиторий
git clone https://github.com/razetka2010/znaniesevera.git
cd znaniesevera

# Запустите локальный веб-сервер
# Для Python 3.x
python -m http.server 8000

# Или для Python 2.x
python -m SimpleHTTPServer 8000

# Для Node.js (если установлен http-server)
npx http-server

# Откройте в браузере
# http://localhost:8000
```

### Вариант 2: Через PHP

```bash
cd znaniesevera
php -S localhost:8000
```

### Вариант 3: Просто откройте файл в браузере

```bash
# На Windows
start public/index.html

# На macOS
open public/index.html

# На Linux
xdg-open public/index.html
```

## 📸 Блог с изображениями и форматированием текста

### Новые возможности

Теперь блог поддерживает:
- 🖼️ **Изображения в новостях** — добавьте URL изображения
- 📝 **Сохранение форматирования** — переносы строк, маркеры, ссылки
- 🔗 **Автоматические ссылки** — URL автоматически преобразуются в кликабельные ссылки
- 📋 **Маркированные списки** — используйте символы • или - для списков

### Как использовать

#### Добавление новости с изображением

1. Перейдите на админ-панель (`admin.html`)
2. Нажмите **"Добавить новость"**
3. Заполните поля:
   - **Заголовок** — название новости
   - **Категория** — выберите категорию
   - **URL изображения** — вставьте ссылку на изображение (опционально)
   - **Краткое описание** — описание для карточки
   - **Полный текст** — полный текст новости

#### Форматирование текста

Полный текст поддерживает следующее форматирование:

```
Первый абзац с основной информацией.
Второй абзац новой строки.

Маркированный список:
• Первый пункт
• Второй пункт
• Третий пункт

Ссылки:
https://example.com

Номерованный список:
1. Первый элемент
2. Второй элемент
```

### Результат отображения

- Каждая строка отображается на новой строке
- Маркеры (•, -, 1., 2.) автоматически отступают
- URL автоматически становятся кликабельными ссылками
- Изображение отображается вверху статьи (если указано)

### Миграция базы данных

Если вы обновили код из старой версии, нужно добавить колонку `image_url` в таблицу `posts`:

#### Автоматическая миграция (рекомендуется)

```bash
# В папке api/
npm run migrate
```

#### Ручная миграция (для Neon/PostgreSQL)

Выполните SQL запрос в панели управления базой данных:

```sql
ALTER TABLE posts 
ADD COLUMN image_url TEXT;
```
